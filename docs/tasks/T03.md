# T03 — Añadir filtros por tags en Proyectos

- Objetivo: Permitir filtrar el listado de Proyectos por tag mediante query param `?tag=`.
- Depende: T02 (asumida hecha: build y checks en verde)
- Módulo dueño: projects
- Archivos que toca: `src/modules/projects/application/filter-projects.ts`, `src/modules/projects/public.ts`, `src/pages/projects/index.astro`, `tests/modules/projects/filter.test.ts`
- Contrato: `filterProjects(projects, tag?)` devuelve los proyectos cuyo `tags` incluye `tag` (case-insensitive) o todos si `tag` es undefined/vacío. La página muestra chips de tags disponibles y resalta el activo.
- Leer antes: `src/modules/projects/domain/project.ts`, `src/modules/projects/public.ts`, `src/pages/projects/index.astro`
- Pruebas de aceptación: casos: sin tag devuelve todos; tag existente filtra; tag inexistente devuelve vacío; case-insensitive.
- Verificación (agente): `pnpm build && pnpm astro check`
- Documentación a actualizar: `CHANGELOG.md`
- Revisión [YO]: UX de chips y estado activo visualmente correctos.
